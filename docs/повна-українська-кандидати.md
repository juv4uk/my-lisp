# Кандидати колонки «Повна українська»

**Статус:** перший повний огляд для власника; не semantic authority і не runtime migration.

Ця таблиця є людиночитаним відображенням staging-профілю `lib/surface/український-профіль-джерела.всм`.
Кожний рядок зберігає той самий numeric semantic ID. Колонка «Повна українська» може бути
ратифікована або змінена власником без зміни semantic identity.

Цей документ спеціально зроблено для ручного перегляду Володимиром: можна проходити рядок за рядком і приймати, змінювати або відхиляти кандидат, не торкаючись чинного runtime.

- Усього stable українських функцій/форм: **140**.
- Поточна назва вже придатна як повна: **121**.

- `кандидат-власника` — `плюс` і `мінус`, прямо запропоновані власником.
- `кандидат-повної-назви` — моя пропозиція для ручного перегляду.
