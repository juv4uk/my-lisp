# Український API `my-lisp`

**Статус:** публічний довідник української програмної поверхні.  
**Машинне джерело покриття:** [`lib/surface/uk-sa-coverage.wsm`](../lib/surface/uk-sa-coverage.wsm).  
**Машинні записи цього довідника:** [`lib/surface/uk-docs.wsm`](../lib/surface/uk-docs.wsm).

Цей документ описує **всі 140 stable українських публічних назв** поточної перекладної поверхні. Він навмисно не маскує внутрішні helper-и та 21 `compatibility-only` ім'я під український API: технічний повний інвентар реалізації лишається у [`FUNCTIONS.md`](FUNCTIONS.md).

Українська назва є людською поверхнею над уже наявною семантичною тотожністю або Lisp-визначенням. Переклад **не створює другої реалізації**.

## Як читати український код

У `my-lisp` ім'я намагається одразу підказувати роль:

- `додати`, `відобразити`, `описати` — щось **роблять або повертають дані**;
- `атом?`, `менше?`, `значення-у-списку?` — **ставлять питання**;
- `встановити-елемент-вектора!` — **змінює** вже наявний об'єкт;
- `порожня-карта`, `порожній-вектор` — готові **значення**, а не запитання.

### Предикат і знак `?`

**Предикат — це функція-питання.** На своїй припустимій області він повертає тільки канонічну істину `t` або канонічну хибу `()`.

Знак `?` є **частиною ідентифікатора**, а не окремим оператором. Українське ім'я предиката читається як звичайне запитання:

```lisp
(атом? 'кіт)                         ; t
(атом? (сполучити 'кіт '()))         ; ()
(менше? 2 5)                         ; t
(значення-у-списку? 'пес (список 'кіт 'пес))   ; t
(текст-порожній? "")                 ; t
```

Три різні види рівності теж видно з назви:

```lisp
(тотожне? 'кіт 'кіт)                   ; ідентичність атомів, Canon EQ
(рівне? 1,5 1.5)                       ; числова рівність
(однакові? (список 1 2) (список 1 2)) ; структурна рівність
```

Не кожна функція, що іноді повертає `()`, є предикатом. Наприклад:

- `отримати-з-карти` повертає `()` або **дані** у формі `(значення)`;
- `підтримувальний-доказ` повертає `()` або **evidence-запис**;
- `та` й `або` короткозамикальні макроси та можуть повернути саме значення аргументу, а не лише `t`/`()`. Тому вони не мають `?`.

### Мутація і знак `!`

Знак `!` означає, що операція змінює вже наявний об'єкт. У поточній українській публічній поверхні таким ім'ям є `встановити-елемент-вектора!`.

Персистентні операції `вставити-в-карту` та `додати-до-вектора` **не** мають `!`, бо повертають нову структуру і не змінюють стару.

### Десяткова кома

У числах можна писати і українську кому, і крапку:

```lisp
(рівне? 12,455 12.455)  ; t
(додати 1,5 2,5)        ; 4
```

Кома є лише альтернативним написанням десяткового роздільника у коректному числовому токені.

## Межа довідника

Ці 140 записів — **публічна перекладна українська поверхня**, а не перелік кожного внутрішнього імені в `lib/*.my`. Акумуляторні робітники, вузли балансування, індексні helper-и та інші implementation details лишаються у технічному [`FUNCTIONS.md`](FUNCTIONS.md).

Правило підтримується виконуваним тестом: stable-покриття і `uk-docs.wsm` мусять мати той самий набір із 140 пар, кожне ім'я з `?` мусить бути класифіковане як предикат, а кожен предикат мусить закінчуватися `?`.

Якщо додається нова stable українська назва, робота не завершена, доки для неї немає запису в цьому довіднику.
