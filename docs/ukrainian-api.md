# Український API `my-lisp`

**Статус:** публічний довідник української програмної поверхні.
**Семантична authority:** [`lib/surface/semantic-registry.lisp`](../lib/surface/semantic-registry.lisp), де `uk` і `ukr` приєднані до numeric semantic IDs.
**Повна жива таблиця назв і статусів:** [`docs/generated/function-table.md`](generated/function-table.md).
**Машинні описи поведінки цього довідника:** [`lib/surface/uk-docs.lisp`](../lib/surface/uk-docs.lisp).

Цей документ пояснює поведінку публічних українських функцій **один раз на semantic ID**. Він не створює окремої реалізації й не дублює опис тільки тому, що одна операція має два українські написання.

## Дві українські поверхні: `uk` і `ukr`

У `my-lisp` дві українські колонки мають різні людські ролі, але одну семантичну тотожність:

- `uk` — коротке ім'я для щоденного програмування: воно має бути компактним, але інтуїтивно зрозумілим україномовній людині;
- `ukr` — повне ім'я: максимально явне українське формулювання тієї самої операції.

Обидва написання, коли вони admitted, ведуть до **того самого semantic ID**. `ukr` не є другою функцією й не має окремої реалізації.

Приклади з поточного registry:

| semantic ID | `uk` | `ukr` | статус `ukr` | Що це означає |
|---:|---|---|---|---|
| `0002` | `атом?` | `атом?` | stable | Повне ім'я вже достатньо коротке, тому колонки збігаються. |
| `0011` | `визначити` | `визначити` | stable | Штучно скорочувати ясне слово не треба. |
| `1045` | `текст-порожній?` | `порожній-текст?` | stable | Обидві назви executable і ведуть до ID `1045`. |
| `1075` | `монотонний-нс` | `монотонний-час-у-наносекундах` | candidate | Повна назва записана для review, але ще не є executable API. |
| `1079` | `поточний-всч` | `поточний-всесвітній-координований-час` | candidate | `candidate` не можна документувати як готову callable surface. |

### Що означають статуси

- `stable` — admitted/executable публічне написання;
- `candidate` — запропоноване написання для review; воно **не** стає API лише тому, що показане в документації;
- `compatibility-only` — історичне/сумісне написання, яке зберігається для старого коду;
- `missing` — для цієї surface ще немає назви.

Єдиним джерелом цих статусів є registry. README, цей довідник і generated tables не мають права самі підвищувати `candidate` до `stable`.

### Як читати детальні таблиці нижче

У колонці **«Українське ім'я»** нижче наведено поточне stable `uk`-написання, бо саме воно є чинним коротким публічним API для описаних функцій. Повний peer `ukr` і його актуальний статус треба дивитися у [`generated/function-table.md`](generated/function-table.md); опис поведінки тут не повторюється вдруге.

Це навмисно розділяє три речі:

```text
numeric semantic ID   — тотожність
uk / ukr              — людські написання
опис нижче            — поведінка цієї тотожності
```

## Як читати український код

У `my-lisp` ім'я намагається одразу підказувати роль:

- `додати`, `відобразити`, `описати` — щось **роблять або повертають дані**;
- `атом?`, `менше?`, `значення-у-списку?` — **ставлять питання**;
- `встановити-елемент-вектора!` — **змінює** вже наявний об'єкт;
- `порожня-карта`, `порожній-вектор` — готові **значення**, а не запитання.

### Предикат і знак `?`

**Предикат — це функція-питання.** На своїй припустимій області він повертає тільки канонічну істину `t` або канонічну хибу `()`.

Знак `?` є **частиною ідентифікатора**, а не окремим оператором. Українське ім'я предиката читається як звичайне запитання:

```lisp
(атом? 'кіт)                         ; t
(атом? (сполучити 'кіт '()))         ; ()
(менше? 2 5)                         ; t
(значення-у-списку? 'пес (список 'кіт 'пес))   ; t
(текст-порожній? "")                 ; t
```

Три різні види рівності теж видно з назви:

```lisp
(тотожне? 'кіт 'кіт)                   ; ідентичність атомів, Canon EQ
(рівне? 1,5 1.5)                       ; числова рівність
(однакові? (список 1 2) (список 1 2)) ; структурна рівність
```

Не кожна функція, що іноді повертає `()`, є предикатом. Наприклад:

- `отримати-з-карти` повертає `()` або **дані** у формі `(значення)`;
- `підтримувальний-доказ` повертає `()` або **evidence-запис**;
- `та` й `або` короткозамикальні макроси та можуть повернути саме значення аргументу, а не лише `t`/`()`. Тому вони не мають `?`.

### Мутація і знак `!`

Знак `!` означає, що операція змінює вже наявний об'єкт. У поточній українській публічній поверхні таким ім'ям є `встановити-елемент-вектора!`.

Персистентні операції `вставити-в-карту` та `додати-до-вектора` **не** мають `!`, бо повертають нову структуру і не змінюють стару.

### Десяткова кома

У числах можна писати і українську кому, і крапку:

```lisp
(рівне? 12,455 12.455)  ; t
(додати 1,5 2,5)        ; 4
```

Кома є лише альтернативним написанням десяткового роздільника у коректному числовому токені.

## Межа довідника

Ці записи — **публічна stable `uk` поверхня**, а не перелік кожного внутрішнього імені в `lib/*.lisp` і не автоматична ратифікація всіх `ukr candidate`. Акумуляторні робітники, вузли балансування, індексні helper-и та інші implementation details лишаються у технічному [`FUNCTIONS.md`](FUNCTIONS.md).

Правило підтримується виконуваними перевірками: stable `uk`-покриття і `uk-docs.lisp` мусять мати той самий набір numeric-ID/name пар; `uk/ukr` spellings і статуси беруться з registry/generated table; кожне ім'я з `?` мусить бути класифіковане як предикат, а кожен предикат мусить закінчуватися `?`.

Якщо додається нова stable `uk` назва, робота не завершена, доки для неї немає опису в цьому довіднику. Якщо додається чи ратифікується `ukr`, її написання й статус не дублюються вручну тут — вони з'являються через registry projection.

## Сумісність назв після смислового аудиту

Історичний смисловий аудит 2026-09-08 переглянув тодішні 140 stable `uk`-назв за точністю та природністю. 42 preferred-назви було уточнено; старі написання лишилися compatibility aliases і не ламають наявні програми. Повний протокол рішень: [`ukrainian-name-audit.md`](ukrainian-name-audit.md).

Окрема сучасна робота над compact-`uk` не повинна повторювати цю помилку як суб'єктивне масове перейменування: коротка форма проходить правила інтуїтивного декодування та blind-test, а `ukr` лишається повною людською опорою.
