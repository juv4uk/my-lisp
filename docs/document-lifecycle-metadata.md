## 2. Мінімальний закритий словник (для нових документів)

```text
DRAFT        — робочий начерк, ще не запропонований формально
PROPOSED     — завершена пропозиція, чекає на рішення (власника/ревʼю)
ACCEPTED     — прийнято, чинне, не потребує подальшого ратифікаційного кроку
RATIFIED     — прийнято ЧЕРЕЗ явний, задокументований ратифікаційний крок
               власника (сильніше за ACCEPTED — є конкретний момент "так")
IMPLEMENTED  — задокументований дизайн реально реалізований у коді;
               документ описує ЩО є, не ЩО планується
EVALUATED    — дослідження/оцінка завершена; вердикт зафіксовано,
               може бути "не зараз" — не сама реалізація
HISTORICAL   — точний знімок минулого стану; НІКОЛИ не переписується,
               щоб відповідати сьогоднішньому (external review files,
               past session records)
SUPERSEDED   — замінено новішим документом; поле `superseded-by`
               вказує на заміну явно
```

Шість статусів, не більше — кожен новий, якщо колись знадобиться,
має заслужити місце так само, як ці (той самий інстинкт, що й
закритий список принципів у `language-core-axioms.md`).

Формат рядка: `**Статус:** <ONE-OF-THE-ABOVE> · <необов'язковий
контекст: дата, автор, задача>` — перше слово після
`**Статус:**`/`**Status:**` завжди з цього словника, решта рядка
вільна.

## 3. Явно НЕ зроблено: масове переписування 102+40 файлів

Задача сама каже: **"Preserve external review files as immutable
time-indexed snapshots; do not rewrite history to current state."**
Жоден наявний документ (жоден з 40 із вільним текстом, жоден зі 102
без статусу) тут не змінений. Причини:

- Історичні файли (зовнішні рев'ю, минулі сесійні записи) — це
  свідомі знімки моменту, коли вони писались; переписування статусу
  заднім числом стирає саме те, що робить їх корисними як історію.
- Масове автоматичне переписування 142 файлів без читання кожного —
  це саме той ризик, від якого застерігає задача, і від якого явно
  застерігав `WSM-SOURCE-VS-PROTOCOL-EXTENSION-POLICY` цієї ж сесії
  ("no bulk rename").
- Конвенція застосовується вперед, до нових документів — не назад.

## 4. Навігація — згенерована, не ручна

`scripts/gen-docs-index.sh` — реальний, запускний скрипт (не
задокументований намір): сканує `docs/*.md`, витягує перший рядок
`**Статус:**`/`**Status:**` кожного файлу, друкує таблицю.
Перевірено живцем: **104 рядки виводу, 62 файли позначені
`UNSPECIFIED`** — чесний, точний знімок поточного стану, не
приховує неоднорідність.

Свідомо **не** комітиться як статичний файл — саме "вручну
скопійоване число стає другим джерелом правди, яке дрейфує", той
самий урок, який `MYLISP-DOCS-DRIFT-SWEEP` щойно застосував до
`docs/testing.md`'s дати. Запускай:

```bash
scripts/gen-docs-index.sh
```
